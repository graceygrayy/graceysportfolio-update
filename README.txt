PORTFOLIO HOMEPAGE UPDATE

This update package contains:
1. index.html
2. home.css

HOW TO ADD IT TO YOUR EXISTING PROJECT
1. Make a backup copy of your current MY-PORTFOLIO folder.
2. Open the project folder in VS Code.
3. Copy index.html and home.css from this package into the main MY-PORTFOLIO folder.
4. Keep your existing image file named me1.jpg in that same folder. The homepage uses it as the profile photograph.
5. Do not delete style.css. The new homepage uses home.css so your existing pages keep their current styling for now.
6. Open index.html in your browser to preview the new homepage.
7. Once approved, commit and push the new files to GitHub Pages.

NOTES
- The homepage uses the existing me1.jpg image.
- The homepage links to your existing about.html, projects.html, skills.html, education.html and contact.html pages.
- The three featured project links are carried over from the existing projects page.
- Your existing pages have not been rewritten in this first homepage update.
